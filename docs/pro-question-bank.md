# 小学科学与初高中物理 Pro 题库说明

专家题库与普通题库独立。小学科学 269 个知识点、高中物理 177 个知识点各新增至少 3 道原创专家题；原初中物理 92 个知识点、每点 4 题的 368 道题保留稳定题号和答案。

新增题以情境应用、实验设计、比较推理和定量分析为主，按对应年级设计。题型为可自动判题的选择题、数值题，均附参考答案与解析。小学和高中新增题均为原创，不标注或冒充历年考试原题。

## 按需加载

- 浏览首页、图谱和普通检测不会请求专家题包。
- 进入专家挑战只并行读取知识点资料和 `data/pro/<topicId>.json`，题包只包含当前知识点的专家题，不请求约 2 MB 的普通总题库，也不请求其他专家题包。
- 题包以紧凑 UTF-8 JSON 发布，单包校验上限为 32 KiB；实际大小、校验摘要和覆盖数量记录在 `data/pro-manifest.json`。运行时不需要先下载这个清单。
- Service Worker 仅在实际访问后缓存该题包，不在安装或后台预热时下载整套题库。再次访问同版本题包可使用本机缓存。
- 题包缺失、格式损坏、学科或知识点不符时停止挑战并保留原进度，不用普通题补齐。

`data/pro-authoring/` 下的五份分学段编写文件和原初中 `data/questions-pro.json` 是编写来源，不由挑战页下载。修改后运行 `python3 scripts/build_pro_banks.py` 生成按点题包；`--check` 只检查生成文件是否与编写来源一致，不写文件。所有生成题包随代码一起提交。

## 挑战与学习记录

先通过同账号、同知识点的普通检测，才可再次进入专家挑战。普通通过显示 ✓；专家通过显示 ⭐、金色边框及光晕。专家失败保留普通通关记录，不把专家失败混入普通薄弱点汇总。专家题少于所设确认题数时，按实际题数完成检测。

普通检测首次直接通关一个知识点计 1 星；专家挑战首次通关再计 1 星。重复通关不重复计分，失败、未测、系统推断掌握不计分。小学科学和物理的成就按本机账号或访客保存，随完整学习备份导出、导入；重复导入不重复发星。每 3 星折算为 1 月亮，已兑换装扮的消费记录继续保留。

运行 `python3 scripts/validate_pro_questions.py` 校验全学段覆盖、独立题号、重复题干、结构、数值答案、初中来源登记以及题包一致性；`python3 tests/test_pro_chunks.py` 检查小题包、生成结果、缺失或损坏文件及预缓存限制；`node tests/test_pro_bank.js` 使用真实专家题检查判题、通关、失败和刷新回放。数值表达式校验不能替代题意与学科概念审阅。
