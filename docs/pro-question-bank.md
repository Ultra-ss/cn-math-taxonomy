# 初中物理 Pro 题库说明

Pro 题库独立存放在 `data/questions-pro.json`，覆盖八年级上册、八年级下册和九年级全一册的 92 个知识点，每点 4 题，共 368 题。普通题库保持独立，题目 ID 不重用。

题目为本站原创训练题，参考下列广东省卷公开转载中的选择题、填空题考查概念与生活情境方式，重新设计条件、数值、选项和解析。它们不是历年中考原题，也不代表官方难度分级。跨学科实践等未直接对应历年考题的知识点使用原创延伸题；不编造原题年份或题号。

题目 `sourceRefs` 表示概念参考，`origin: original` 表示原创。来源目录见 `data/pro-sources.json`；公开预览或转载内容仅用于核对，不收录原卷附件。核对日期：2026-11-16。

普通检测首次直接通关一个知识点计 1 星；专家挑战首次通关再计 1 星。重复通关不重复计分，失败、未测、系统推断掌握不计分。成就按本机孩子档案或访客保存，随完整学习备份一起导出、导入。每 5 星换算为 1 月，每 5 月换算为 1 日，累计积分仍按原始星数显示。

运行 `python3 scripts/validate_pro_questions.py` 校验每点题数、ID 隔离、结构、数值答案和来源登记；`python3 scripts/verify_questions.py --file data/questions-pro.json` 补充检查答案表达式。表达式校验不能替代对题意和概念的人工审阅。
