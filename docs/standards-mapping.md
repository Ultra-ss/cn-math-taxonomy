## 引用格式

知识点的 `standards` 数组通过稳定 ID 引用条目，例如：

```json
{"id": "cps-2022:2.2.1", "confidence": "exact"}
```

- `exact`：当前项目认为条款直接涉及该知识点；不是官方认证。
- `inferred`：当前项目认为属于前提、应用或延伸，应填写 `note` 说明。
- 科学 ID 以 `css-2022:` 开头；初中物理以 `cps-2022:` 开头；高中物理以 `cps-hs-2017:` 开头。
- 页码未知就保留「待核」；不要补写未经核实的页码或把 `verbatim` 改为 `true`。
- 修改条目 ID 时必须同步更新所有知识点引用。

运行 `npm test` 检查重复 ID、引用完整性、字段、学科范围及图结构。校验不验证条文或学科答案的实质正确性。实际修订应记录采用的课标版本、来源、页码和核验方式。
