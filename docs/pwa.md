# 离线使用、本机数据与备份

## 安装与缓存

`manifest.webmanifest` 和 `assets/pwa.js` 提供添加到桌面的入口。页面只在 HTTPS 或 localhost 注册 Service Worker；iOS 使用分享菜单的“添加到主屏幕”。

`sw.js` 按版本缓存核心页面、脚本、样式、字体和图标。当前版本已有的资源直接读缓存，切页不再等待网络；缺少的资源联网加载并缓存。更新代码、缓存清单或数据时升级 `sw.js` 中的 `VERSION`，新核心完整缓存后才替换旧版本，避免混用。

安装时不再整批下载所有装扮和题库，核心下载最多并发四个。页面就绪后延迟、空闲时顺序补齐四份图谱元数据，题库和装扮在访问时缓存。首次访问以及未缓存内容仍需联网，已经缓存的页面、题目和图片可离线使用。

图谱布局通过 Worker 在后台计算，相同结构和节点尺寸的结果可在当前标签页跨页面复用。几何缓存使用 `sessionStorage` 的 `cnmGraph.layout.v1`，与学习记录、积分、皮肤账本分开；缓存不可用时仍能计算，Worker 不受支持或加载失败时回退原布局算法。

## 本机数据

本站仅提供科学、物理，没有账号或自动跨设备同步。浏览器按站点保存数据；换域名、换浏览器或清理站点数据前，应导出学习备份。

| localStorage 键 | 内容 |
| --- | --- |
| `cnmChildren.v1` | 孩子资料和当前选择，最多 8 个孩子 |
| `cnmChildren.records.v1` | 按孩子保存的检测历史，通常保留最近 40 条 |
| `cnmWrong.v1` | 按孩子或 guest 保存的错题，通常每桶 300 题 |
| `cnmBlind.local.v1` | 本机知识点状态与错次台账，通常最多 200 点 |
| `cnsDiagnose.session.v1` | 科学当前检测会话 |
| `cnpDiagnose.session.v2` | 物理当前检测会话 |
| `cnmDiagnose.archived.v1` | 导入时遇到冲突而保留的其他检测进度 |
| `cnmProgress.v1` | 按孩子或访客记录每次直接检测结论，用于图谱 ✓ / × |
| `cnmLastLocation.v1` | 本机最后查看的学科、教材和知识点，用于返回图谱和首页继续学习提示（显示偏好） |

从备份合并产生的更大历史集合不会因合并或之后正常写入立即截断。教材版本目前是孩子资料的备注；科学内容按教科版、物理按人教版组织，不会随档案备注自动切换数据。

## 章节检测完成度

图谱目录在每章右侧显示 `已完成检测数/整章知识点数`。完成是指已有直接检测结论：通过、薄弱、不稳均计入；仅打开、尚未形成结论或从先修关系推断的掌握不计入。进度沿用当前孩子或本机访客的图谱检测记录，不混用其他人的数据；搜索和领域筛选不会缩小章节总数。✓ / × 继续表示是否通过。

## 下次续看

浏览图谱的有效知识点时，会记录最后位置，包括学科、所选教材、节点、全图/局部视图与层数。从任意页面点击导航“知识图谱”，或打开未指定内容的图谱入口，会恢复该位置。导航图谱链接使用 `data-resume-graph`，不会被当前页面自动注入的学科参数覆盖。多册浏览在显示偏好的原 `v1` 记录中增加可选 `volumes` 数组，单册仍使用原 `volume` 字段；旧记录继续可读，学习备份格式不变。

下次直接打开站点首页或 PWA 时，首页正常显示，并在有有效记录时弹出“是否继续学习”；点击“继续学习”才进入上次知识点，点击“暂不继续”或按 Esc 留在首页且保留记录。主动点击“首页”（`home=1`）可直接重新选教材，不重复弹窗。首次使用没有记录则显示物理教材选择；显式学科、册次、知识点分享链接仍优先于本机记录。

记录仅保存在当前浏览器，不上传，作为显示偏好不进入学习备份。存储不可用或记录已失效时正常进入教材选择，避免反复跳转。

## 手机图谱视图与画面位置

手机目录的搜索、学段和教材筛选默认收起，可用教材标题栏右侧“筛选”展开或收起；收起与切换视图不清空筛选值。收起内容不会进入键盘焦点，Escape 可关闭筛选并回到入口；切换电脑宽度时恢复全部筛选控件。

手机图谱使用底部“目录 / 图谱 / 详情”切换，三个工作区保留各自内容；目录和详情独立滚动。切换视图不会重建图谱，保留选中点及平移、缩放。当前标签页的 `sessionStorage` 中，`cnmExplore.viewport.v1` 保存最近一个场景的画面中心、缩放和祖先展开状态，用于从检测、首页或个人中心返回以及刷新。记录按学科、所选教材集合、知识点、视图、层数和节点尺寸匹配；不同教材组合不共用画面位置，跨尺寸布局不兼容时仍保留知识点并重新对准。该显示偏好不进入学习备份，关闭标签页后不保证保留；长期最后知识点仍由 `cnmLastLocation.v1` 保存。存储不可用或损坏不影响浏览。

## 检测答题与旧记录

检测开始页先显示“开启一口气挑战”，按选择的教材顺序实际作答；“每次检测题目数量修改”默认折叠，展开后可调整题量、确认题数及搜索目标。个人中心集中展示“我的薄弱知识点”与“检测进度与结果”，通过 `diagnose/?subject=physics&resume=1`（或 `science`）恢复保存的检测、查看结果，并沿用原记录归属与返回位置。读取失败时保留原数据。

题目视图以 `testing-active` 状态隐藏大导航、个人档案、PWA 提示与关于入口，只显示题目和作答操作。结果与开始页恢复完整导航。术语更名不改变 `diagnose/` 地址、`diagnostic_question` 数据字段或已有本机存储键；旧记录标签只在页面及分享图中转换显示，原记录和备份保持兼容。

## 导出与导入

“本地个人中心”的“导出全部学习数据”生成 `learning-backup-*.json`，版本为 2；没有建立孩子档案也能迁移本机学习进度。包含所有孩子资料、已存检测记录、错题、当前两科检测、薄弱台账、图谱检测标记及其他检测进度。数据只在浏览器读取，不上传服务器。

```json
{
  "format": "cn-math-taxonomy.children",
  "version": 2,
  "exportedAt": "2026-11-16T00:00:00.000Z",
  "profiles": {"v": 1, "current": null, "children": []},
  "records": {},
  "learning": {
    "wrongbook": {},
    "sessions": {},
    "blindspots": {"v": 1, "byId": {}},
    "archivedSessions": [],
    "progress": {"v": 1, "byChild": {}}
  }
}
```

- `sessions` 按 `science`、`physics` 存放完整会话；归档每项为 `{subject, session}`。教材顺序会话使用 `mode: "textbook"`、`order: "book"`，并保存册次和检测归属。会话可带规范站内图谱路径 `returnTo`，备份恢复后仍能“返回继续”；旧会话缺少此字段仍可导入。
- `progress` 按孩子或 `guest` 保留各次直接检测结论，不从档案汇总的“掌握”项推断勾选。旧版 v2 没有该字段也可以导入，且不会清空本机已有标记。撤销后的空状态会保留，避免导入旧备份时重新出现已撤回的结论。
- 仍支持版本 1 的科学、物理档案备份。它只含 `profiles` 和 `records`，导入不会清除本机的错题、进度和薄弱台账。
- 备份不含显示偏好（包括最后浏览位置）、检测设置、独立的已见题目列表、PWA 安装提示状态或访问统计。历史摘要保留原本存储的字段，不会补造旧记录中不存在的作答内容。
- 支持 UTF-8 BOM，文件上限 10 MB。读取失败、损坏数据、未知格式和版本会报错，不生成或导入空白替代数据。

选择文件后先显示新增和更新数量，点击“确认合并导入”才写入。取消或预览不会更改本机数据。JSON 含孩子昵称和学习资料，应自行保管。

## 合并与冲突规则

1. 同一孩子 ID：保留本机资料、合并历史。同名不同 ID：保留两份，导入昵称加“（导入）”。最多 8 个孩子，超过就停止，不删除已有档案。
2. 检测记录按 `key` 去重，以 `savedAt`、`updatedAt` 较晚的时间选择状态；错题按桶和 `qid`，薄弱台账按知识点 ID，采用较新状态。时间相同保留本机。错次计数取较大值，重复导入不会重复累加。
3. 本机缺少某学科会话时直接恢复；已有不同会话时保留本机会话，把导入会话放入“其他检测进度”。在档案页可恢复其中一份，原活动会话会存入列表，双方进度均保留。
4. 预览后本机数据有变化，会要求重新预览。写入八份存储时如失败，回滚之前写入的键；回滚失败会明确提示，不能报告导入成功。存储空间不足时保留备份文件，先整理浏览器空间。

## 访问统计

`assets/stats-config.js` 的 `cloudflareToken` 和 `endpoint` 默认留空，不加载外部统计信标，也不向外发送访问事件。本机仍可能记录访问天数、安装提示状态。

如需统计，只填自己管理的 Cloudflare Web Analytics token 或 HTTPS 采集地址。`assets/stats.js` 的事件包含名称、来源、页面路径和时间，现有事件不含孩子昵称或作答内容。回调 `onEvent` 仅在显式配置时调用。

## 验证

运行 `npm test` 检查档案、备份合并、重复导入、旧格式兼容、错误文件和写入失败回滚。浏览器检查使用 `CHROME=/usr/bin/chromium npm run test:browser`（或把 CHROME 指向自己的 Chrome/Chromium），覆盖导出下载、文件选择、导入预览、取消、冲突恢复和手机布局。浏览器检查单独执行，不要求默认测试环境安装浏览器。
