# 科学与物理诊断

纯静态的本地诊断工具：选择知识点、整章或册次，沿先修关系出题，生成薄弱点与补学路径。运行方式和部署配置见[项目说明](../README.md)。

## 数据与算法

当前仅提供小学科学（教科版）与初高中物理（人教版），共 538 个知识点、974 条先修关系、2152 道题。两科分别建图，没有跨学科先修边。

- 默认同一知识点连续答对 3 题判为掌握，可选 2、3、4 题；每点目前有 4 题，实际确认数不会超过可用题数。旧设置中的 5 题自动改为 4 题。
- 答错后出同级或更简单的确认题；确认答对标为「不稳」，仍错标为「薄弱」并回溯先修。
- 达到题量上限后保留「未测」状态。单点/整章默认 16 题（可设 8–30），整体筛查默认 40 题（可设 20–60）。
- 掌握可能用于推断先修掌握；筛查模式只在目标范围内回溯，以 hard 先修关系进行掌握推断。结论依赖题库和图谱质量，仍需教师审核。
- 选择题与简单数值题可自动判分；无法可靠比较的答案交给用户自评。结果页可更正，并重新计算。

## 页面入口

参数可以组合，`subject` 为 `science` 或 `physics`：

| 参数 | 例子与用途 |
| --- | --- |
| `target` | `?subject=physics&target=cnp_071`，直接诊断欧姆定律；多目标以逗号分隔 |
| `grade` | `?subject=science&grade=一年级`，按年级整体筛查 |
| `volume` | `?subject=physics&volume=八上`，按册筛查 |
| `chapter` | 使用知识点中的册章标识，空格需要 URL 编码 |
| `demo=1` | 模拟答题并显示结果，不保存学习进度 |
| `step` | 配合演示，只模拟指定题数后停在答题页 |
| `seed` | 固定选题随机种子，用于复现 |
| `limit` | 指定本次题量上限 |
| `confirm` | 指定确认题数 2、3、4；旧值 5 规范化为 4 |

高中 `grade` 的数字用于区分册次，不直接代表真实学年。具体入口建议从首页年级卡片或诊断页选择，避免手写内部编码。

## 文件与保存

- `engine.js`：图结构、选题、判题和诊断状态，浏览器与 Node 通用。
- `app.js`：加载数据、路由、开始/答题/结果页、本机保存与导出。
- `share.js`：分享图；`style.css`：诊断与打印样式。
- `../data/`：知识点、先修关系、题库与课标；`../assets/children.js`：档案和学习备份。

档案、错题和诊断进度保存在当前浏览器，没有账号或自动同步。跨设备前应在档案页导出学习备份，导入时先预览再合并。备份范围、冲突处理和旧格式兼容见[本机数据说明](../docs/pwa.md)。演示不写入学习记录。

诊断结果 JSON 是单轮结果摘要，不能替代档案页的学习备份。打印、分享图和错题练习页也不包含所有可恢复状态。

## 校验

在仓库根目录运行 `npm test`。修改算法应覆盖答错确认、根因回溯、题量上限和重放；修改保存逻辑应覆盖已有数据、备份合并和写入失败回滚。
