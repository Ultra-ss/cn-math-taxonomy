# 科学·物理知识图谱

一个纯静态的科学、物理学习与诊断网站。初次打开默认进入**物理**，也可以显式切换到**小学科学**。本机已有浏览记录时，下次直接打开网址会续上最后的教材知识点；导航“首页”仍可重新选教材。首页先选教材，八年级上、下册分别进入；包含本册图谱、按教材顺序检测、单点自适应诊断、孩子档案和本机错题本。

在线地址：<https://physicalmap.pages.dev/>

## 本地修改

无需 Node.js 依赖或构建步骤。在项目根目录运行：

```bash
python -m http.server 8765
```

然后打开 <http://localhost:8765/>。不要直接通过 `file://` 打开，否则浏览器会阻止 JSON 数据加载。

主要文件：

```text
index.html + assets/home.js       首页、学科切换、实时统计与年级入口
explore/                          教材选择、本册全图与局部先修图
diagnose/                         教材顺序检测、单点诊断与结果分享
children/                         本地个人中心：孩子档案、盲区与历史
wrongbook/                        本机错题本
assets/progress.js                按孩子或访客保存真实检测结论
assets/last-location.js           本机最后浏览位置与安全续看
assets/                           共用样式与脚本
data/topics.json                  科学、物理知识点
data/dependencies.json            先修关系
data/questions.json               题库
data/cn-curriculum-standards.json 课标条目
tests/                            两科范围与交互测试
```

档案、诊断记录和错题只保存在当前浏览器的 `localStorage`，不会自动同步到其他设备。清除浏览器数据或更换设备前，请在“本地个人中心”里“导出全部学习数据”；备份包含错题、两科诊断进度、薄弱台账、图谱检测标记及进度归档，支持旧版档案备份导入。遇到同学科进度冲突会保留双方，详见[备份规则](docs/pwa.md)。

选择一册教材后，按教材知识点顺序从第一点开始检测，每个点都需要实际作答；不会因先修推断跳过未测点。题量上限后可继续下一轮，保留已答进度。单点诊断仍沿先修关系定位根因。

图谱知识点框右上角的绿色 ✓ 表示实际检测通过，红色 × 表示本次未通过（薄弱或不稳）；未检测与推断掌握不加标记。标记按当前孩子或本机访客分别保存，重新检测、更正和撤销会更新。

手机图谱默认收起导航和扩展工具，保留教材标题与目录/选项入口，将主要空间留给图谱。第一次点击知识点方框选中，再次点击同一方框会询问是否进入诊断；选择“我要试试”进入该点检测，“不”关闭小窗并保留选中状态。

单点检测结束后，结果页默认只显示结论，详细分析、答题记录和更多操作由按钮展开。“返回继续”会回到进入诊断前的教材图谱、选中节点及筛选状态，方便接着检查其他知识点。

诊断确认题数为 2、3、4（默认 3），旧设置中的 5 题会兼容为 4。统计默认关闭，采集地址留空。课标来源和待核状态见[课标说明](docs/standards-mapping.md)，本轮没有新增逐页内容核验。

## 验证与部署

```bash
npm test
```

可另行运行 `CHROME=/usr/bin/chromium npm run test:browser` 检查真实浏览器备份流程。

默认测试与 `.github/workflows/ci.yml` 对齐，覆盖数据、175 道题目配图、答案格式、诊断引擎、档案备份、错题本及历史兼容。自动核验通过不等同于学科内容经教师审核。

本项目可直接部署到 Cloudflare Pages：连接本仓库的 `main` 分支，框架选择「无」，构建命令使用 `exit 0`，输出目录使用 `/`。推送到 `main` 后，Cloudflare Pages 会自动构建并更新网站。

建议先在独立分支检查修改与预览，再合并到正式分支。手动部署脚本 `scripts/deploy-cf.sh` 已指向 `physicalmap`，但必须显式配置自己的 `CLOUDFLARE_ACCOUNT_ID` 与 `CLOUDFLARE_API_TOKEN`；它会发布到正式站点，不应当作本地预览命令。
